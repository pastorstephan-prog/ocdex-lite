# Support

Ocdex Lite is a small, community-supported open-source project.

## Questions and bugs

- Search existing GitHub issues first.
- Open an issue for a reproducible bug, documentation gap, or focused feature request.
- Include your macOS version, Node.js version, Codex CLI version, the command you ran, and sanitized error output.
- Never include tokens, tokenized URLs, `.phone-token`, private screenshots, session files, or account details.

The maintainer cannot promise individual setup help, environment-specific troubleshooting, response times, or paid priority support.

## Security reports

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) and use a private security advisory.

## Sponsorship

Ocdex Lite is a maintenance-only experiment. GitHub Sponsors may support best-effort maintenance, compatibility checks, and documentation, but the project is not an active commercial product. Sponsorship is voluntary and does not purchase support, consulting, feature priority, or a service-level agreement.
