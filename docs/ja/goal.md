# Commercial Goal

Ocdex Liteは、まずPWA版としてGitHub公開します。

最初の収益化は次の形です。

- OSS本体
- 有料セットアップガイド
- GitHub Sponsorsまたは外部決済
- 必要に応じた導入支援

最初にはやらないもの:

- App Store版
- GitHub Marketplace有料アプリ
- hosted relay
- team dashboard
