# Commercial Goal

Ocdex Liteは、まずPWA版としてGitHub公開します。

最初の収益化は次の形です。

- OSS本体
- 500円のnote有料記事
- 個別サポートなし
- 導入代行なし
- 環境別の動作保証なし

最初にはやらないもの:

- App Store版
- GitHub Marketplace有料アプリ
- hosted relay
- team dashboard
