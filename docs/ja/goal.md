# 現在の位置づけ

当初の商用計画は終了しました。モバイル利用者の多くにはOpenAI公式Codex Remoteを先に案内すべきであるため、Ocdex Liteを有料リモート操作商品として販売しません。

現在の範囲:

- 保守限定のOSS実験
- 自前LAN/VPN UIとapp-serverの参考実装
- best-effortのセキュリティ・互換性修正
- 有料ガイド、個別サポート、導入代行、環境別保証は提供しない
